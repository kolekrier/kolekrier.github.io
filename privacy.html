Privacy Policy — Kole Content Strategist

Last updated: October 17, 2026

What this app is

Kole Content Strategist is a personal tool used only by Kole Krier, the owner of the KoleKrier YouTube channel, to review his own channel's performance and plan content. It's not offered to the public.

What data it accesses

With the channel owner's permission, the app uses Google's YouTube Data API and YouTube Analytics API with read-only access to the owner's channel: video titles, publish dates, view counts, watch time, audience retention and subscriber changes. It cannot upload, edit or delete anything.

How data is used and stored

The data is saved only on the channel owner's own computer and is used only to analyze that channel's videos. It is not sold, shared with third parties, or used for advertising.

Kole Content Strategist's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
